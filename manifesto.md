# Engineering Manifesto

## 1. AI usage is encouraged

Ми активно використовуємо AI для implementation, investigation та review.

## 2. Author owns all generated code

Автор PR відповідає за весь код у PR незалежно від того, написаний він вручну чи AI.

## 3. Author must self-review the PR

Перед request review автор вручну переглядає фінальний diff.

## 4. AI review does not replace human review

Reviewer може використовувати AI як інструмент, але фінальне review має виконувати людина.

## 5. Approve means understanding

Approve означає, що reviewer достатньо розуміє change і погоджується з його integration у codebase.

## 6. PRs should be reviewable

Великі features потрібно розбивати на smaller logical PRs, якщо це практично можливо.

## 7. Large changes require context

Для великих або архітектурно важливих changes варто робити короткий walkthrough або додавати design context.
