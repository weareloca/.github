# Engineering Manifesto

## 1. AI usage is encouraged

We actively use AI for implementation, investigation and review.

## 2. Author owns all generated code

The PR author is responsible for all code in the PR, regardless of whether it was written manually or by AI.

## 3. Author must self-review the PR

Before requesting review, the author manually goes through the final diff.

## 4. AI review does not replace human review

A reviewer may use AI as a tool, but the final review has to be done by a human.

## 5. Approve means understanding

An approve means the reviewer understands the change well enough and agrees with its integration into the codebase.

## 6. PRs should be reviewable

Large features should be split into smaller logical PRs whenever it is practical.

## 7. Large changes require context

For large or architecturally significant changes, provide a short walkthrough or add design context.
